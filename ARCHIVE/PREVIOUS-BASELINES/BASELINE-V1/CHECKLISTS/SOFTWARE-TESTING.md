# Checklist — Software

- [ ] Requisitos e critérios de aceite definidos.
- [ ] Estado inicial e branch registrados.
- [ ] Dependências e versões identificadas.
- [ ] Alterações pequenas e revisáveis.
- [ ] Testes unitários relevantes.
- [ ] Testes de integração/E2E conforme risco.
- [ ] Lint/typecheck/build executados quando disponíveis.
- [ ] Erros e warnings avaliados.
- [ ] Segurança e segredos revisados.
- [ ] Documentação atualizada.
- [ ] Resultado reproduzível.
