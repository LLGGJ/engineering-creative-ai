# Contributing

Contribuições são bem-vindas.

- Abra issue descrevendo problema, evidência e proposta.
- Mantenha módulos focados e carregáveis sob demanda.
- Prefira documentação oficial e links verificáveis.
- Inclua data de revisão para referências sensíveis a versão.
- Não inclua credenciais, dados privados ou código sem licença compatível.
- Para novos fluxos, adicione checklist ou caso de avaliação.
- Não prometa capacidades que dependem de conectores não disponíveis.
