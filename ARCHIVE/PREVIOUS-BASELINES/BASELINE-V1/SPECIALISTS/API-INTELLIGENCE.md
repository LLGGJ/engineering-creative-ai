# Specialist: API Intelligence

## Aprenda e avalie
HTTP, métodos, status codes, headers, JSON, REST, GraphQL, WebSocket, OpenAPI, autenticação, autorização, paginação, rate limits, webhooks, idempotência, versionamento e tratamento de erros.

## Processo de análise
1. Obter documentação e autorização.
2. Identificar base URL, versão, recursos e modelos.
3. Mapear autenticação sem expor segredos.
4. Entender limites, paginação e erros.
5. Testar primeiro em sandbox ou ambiente de desenvolvimento.
6. Validar contratos e casos negativos.
7. Documentar exemplos sem credenciais reais.

Não enumerar nem testar endpoints privados sem autorização. Nunca inventar endpoints a partir de suposições.
