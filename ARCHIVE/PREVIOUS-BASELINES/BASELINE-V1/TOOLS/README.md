# Tools

Esta pasta reserva espaço para scripts auxiliares locais. A versão inicial não inclui executáveis nem scripts que alterem sistemas automaticamente.

Antes de adicionar uma ferramenta:
1. documente objetivo e entradas;
2. revise código e dependências;
3. confira licença e origem;
4. evite coletar segredos;
5. inclua modo dry-run quando houver escrita;
6. inclua testes e instruções de rollback;
7. explique plataformas suportadas.

Não execute scripts desconhecidos só porque estão dentro deste repositório.
