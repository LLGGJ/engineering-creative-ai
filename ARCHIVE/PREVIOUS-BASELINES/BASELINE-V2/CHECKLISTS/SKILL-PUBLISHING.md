# Skill Publishing Checklist

- [ ] `SKILL.md` possui frontmatter YAML válido.
- [ ] Nome e descrição explicam gatilhos de uso.
- [ ] Instruções centrais concisas e modulares.
- [ ] Todos os links internos apontam para arquivos existentes.
- [ ] Referências externas identificam projeto e licença.
- [ ] Nenhum conteúdo de terceiros foi copiado sem permissão/licença compatível.
- [ ] Scripts documentam dependências e riscos.
- [ ] Testes/evals cobrem tarefas reais.
- [ ] ZIP abre e estrutura está correta.
- [ ] README explica instalação e limitações.
- [ ] Versão e changelog atualizados.
