# Contributing

Contribuições são bem-vindas. Adicione módulos focados, com instruções acionáveis, referências oficiais, exemplos, limitações e testes. Mantenha carregamento progressivo. Não copie skills de terceiros sem respeitar licença e atribuição. Não adicione credenciais, dados privados ou scripts perigosos. Atualize changelog e casos de avaliação.
