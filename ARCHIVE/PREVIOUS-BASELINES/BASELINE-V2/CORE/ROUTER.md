# Task Router

1. Classifique o pedido: software, análise de artefato, web design, vídeo, pesquisa, segurança ou operação.
2. Leia somente o especialista indicado.
3. Identifique se é criação nova, edição de material existente, análise ou manutenção.
4. Descubra ferramentas disponíveis e dependências instaladas.
5. Defina resultado, formato, resolução, prazo e critérios de aceite; pergunte somente o que bloquear a execução.
6. Faça plano curto, execute etapas reversíveis, valide e reporte.
