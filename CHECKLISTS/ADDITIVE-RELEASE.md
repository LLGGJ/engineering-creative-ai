# Checklist de release aditiva

- [ ] Nenhum arquivo/pasta publicado foi removido ou renomeado.
- [ ] Novos caminhos têm nomes estáveis e propósito claro.
- [ ] Arquivos substituídos mantêm histórico/migração quando necessário.
- [ ] `CHANGELOG.md` atualizado.
- [ ] `PACKAGE-MANIFEST.json` regenerado.
- [ ] Testes e validador executados.
- [ ] Links internos revisados.
- [ ] Limitações e mudanças documentadas.
- [ ] ZIP extraído em pasta limpa e validado.
