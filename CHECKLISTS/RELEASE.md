# Checklist — Release

- [ ] Versão e changelog atualizados.
- [ ] Testes e build executados.
- [ ] Configuração de produção revisada.
- [ ] Segredos e certificados protegidos.
- [ ] Backup/rollback planejado.
- [ ] Notas de release preparadas.
- [ ] Autorização explícita para publicar.
- [ ] Publicação confirmada pela plataforma.
- [ ] Smoke test pós-release.
