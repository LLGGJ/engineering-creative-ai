# Checklist — Segurança defensiva

- [ ] Escopo e autorização confirmados.
- [ ] Segredos fora do código e logs.
- [ ] Menor privilégio aplicado.
- [ ] Entradas validadas.
- [ ] Autenticação e autorização revisadas.
- [ ] Dependências e licenças verificadas.
- [ ] Dados sensíveis protegidos.
- [ ] Logs sem credenciais.
- [ ] Configurações de produção revisadas.
- [ ] Achados classificados e mitigação proposta.
