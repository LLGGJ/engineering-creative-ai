# Project Memory Template

Copie este modelo para `PROJECT_STATE.md` dentro de cada projeto, quando houver permissão para gravar arquivos.

```markdown
# Project State
## Objetivo
## Estado atual
## Arquitetura
## Decisões e justificativas
## Arquivos/módulos relevantes
## Ambiente e versões
## Comandos úteis
## Testes executados e resultados
## Problemas conhecidos
## Riscos
## Próximos passos
## Última atualização
```

Não armazene senhas, tokens, chaves privadas, dados pessoais desnecessários ou conteúdo confidencial sem necessidade e autorização. Atualize fatos, não opiniões; remova decisões obsoletas.
