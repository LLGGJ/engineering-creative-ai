# Fundamentos essenciais

## Engenharia de software
Requisitos descrevem o que o sistema deve fazer e as restrições. Arquitetura define componentes e relações. Implementação transforma decisões em código. Testes fornecem evidência limitada sobre comportamento.

## Engenharia reversa
É o processo de inferir estrutura e funcionamento a partir de artefatos observáveis. A reconstrução é aproximada e deve declarar incertezas.

## Segurança
Confidencialidade, integridade e disponibilidade são objetivos centrais. Menor privilégio, defesa em profundidade, validação de entrada e gestão de segredos reduzem riscos.

## Web
HTML descreve estrutura, CSS apresentação e JavaScript comportamento. Frameworks e bibliotecas devem ser escolhidos por necessidade, compatibilidade e manutenção, não apenas tendência.

## 3D na web
WebGL permite renderização acelerada; Three.js abstrai partes da API gráfica. Conteúdo 3D pode aumentar custo de CPU/GPU, memória e rede. Usar com propósito, otimizar assets e oferecer fallback.

## APIs
Contrato de API define operações, entradas, saídas, autenticação, erros e limites. Documentação não substitui validação em ambiente autorizado.
