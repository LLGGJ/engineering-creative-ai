# API Engineering

Ensine HTTP, REST, GraphQL, WebSocket, JSON, OpenAPI, autenticação, autorização, paginação, rate limits, idempotência, webhooks, versionamento e tratamento de erros.

## Método
1. Obter documentação oficial e autorização.
2. Mapear recursos, métodos, modelos e contratos.
3. Identificar autenticação sem expor segredos.
4. Entender limites e erros.
5. Testar em sandbox/desenvolvimento.
6. Criar exemplos sem credenciais reais.
7. Documentar compatibilidade e breaking changes.

Não inventar endpoints nem testar sistemas privados sem autorização.
