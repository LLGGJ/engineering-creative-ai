# Defensive Security

Audite somente sistemas próprios ou autorizados. Defina escopo, ativos, fronteiras de confiança e dados sensíveis. Revise autenticação, autorização, validação, sessão, segredos, dependências, configuração, logs e backups. Para cada achado informe evidência, impacto, severidade, condição, mitigação e reteste. Não explorar terceiros nem exfiltrar dados.
