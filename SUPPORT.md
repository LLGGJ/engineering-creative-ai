# 🆘 Suporte

Para relatar problemas, abra uma issue no repositório de origem ou use os templates em `.github/ISSUE_TEMPLATE/`.

## 📣 Antes de abrir o reporte

Inclua:

- 🏷️ versão do pacote
- 🧰 ambiente e ferramentas envolvidas
- 🔁 passos para reproduzir
- 🎯 resultado esperado e obtido
- ⚠️ logs relevantes, sem segredos

Remova tokens, dados pessoais e informações confidenciais antes de publicar logs.

## 🔍 Template rápido

```text
Versão:
Ambiente:
Passos:
Resultado esperado:
Resultado obtido:
Risco/impacto:

```

## 🧭 Quando abrir suporte

- erro de validação
- quebra de compatibilidade aditiva
- problema de instrução ou roteamento
- problema em módulos específicos
- pedido de melhoria relevante para o pacote
