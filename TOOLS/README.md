# Tools

Esta pasta descreve ferramentas e utilitários opcionais. O pacote não instala nem autentica ferramentas automaticamente.

## Categorias comuns
- Navegador e pesquisa web para fontes atuais.
- Git/GitHub para versionamento e colaboração.
- Python/Node para validação e prototipagem.
- Android SDK/Gradle para projetos Android.
- FFmpeg/Blender para pipelines audiovisuais.
- Ferramentas de inspeção estática/dinâmica para análise autorizada.

Antes de usar, confirme disponibilidade, versão, licença e permissões. Consulte documentação oficial em `REFERENCES/REFERENCE-INDEX.md`.
