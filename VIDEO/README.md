# Video production modules

- `VIDEO-FROM-ZERO.md`: pipeline completo de briefing até exportação.
- `AI-VIDEO-GENERATION.md`: geração com modelos de vídeo.
- `BLENDER-3D-PRODUCTION.md`: produção 3D.
- `CODE-ANIMATION.md`: motion por código.
- `FOOTAGE-EDITING.md`: edição de filmagem real.
- `AUDIO-AND-CAPTIONS.md`: áudio, mixagem e legendas.
- `FFMPEG-COOKBOOK.md`: operações de mídia com FFmpeg.
- `VIDEO-QA.md`: controle de qualidade audiovisual.

Cada fluxo depende das ferramentas e licenças disponíveis no ambiente.
