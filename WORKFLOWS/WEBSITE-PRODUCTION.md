# Workflow: Business Website Prompt Production

1. Pesquisar a empresa e reunir fontes públicas.
2. Confirmar nome, serviços, localização, identidade e contatos.
3. Avaliar site atual e experiência móvel, se houver.
4. Identificar público, objetivo e conversão.
5. Escolher direção visual adequada; usar Profitize Build como referência de inspiração após análise.
6. Escrever prompt de implementação completo para outra IA.
7. Incluir conteúdo confirmado e placeholders para lacunas.
8. Incluir performance, acessibilidade, SEO, responsividade e testes.
9. Revisar o prompt para remover afirmações inventadas.
10. Entregar prompt, fontes e checklist. Não escrever o código do site empresarial.
