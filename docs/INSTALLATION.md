# Instalação e uso

## Requisitos

- Um cliente de IA que aceite Skills ou instruções baseadas em arquivos.
- Para validação local: Python 3.10+.
- Para o portal: qualquer servidor HTTP estático ou GitHub Pages.
- Ferramentas de domínio (Android SDK, Blender, FFmpeg, Node etc.) são opcionais e instaladas separadamente.

## Instalação genérica

1. Baixe e extraia o pacote.
2. Importe como Skill se o cliente suportar esse formato.
3. Caso contrário, forneça `SKILL.md` como instrução e os módulos pertinentes como arquivos de referência.
4. Teste com uma tarefa pequena.

## Importante
Compatibilidade e diretórios de instalação variam entre Claude Desktop, Claude Code e outros clientes. Consulte sempre a documentação atual do produto. O pacote não promete instalação universal.
