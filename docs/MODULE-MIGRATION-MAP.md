# Module migration map

A união das bases antigas deixou nomes próximos que não devem ser apagados automaticamente. Esta tabela aponta os caminhos preferidos para novas tarefas e mantém os alternativos disponíveis.

| Tema | Caminho preferencial | Caminho mantido por compatibilidade |
|---|---|---|
| Roteamento | `CORE/ROUTER.md` | `CORE/OPERATING-MODEL.md` complementa o fluxo |
| Conectores | `CORE/TOOL-AND-CONNECTOR-INTELLIGENCE.md` | `CORE/CONNECTOR-INTELLIGENCE.md` |
| Memória de projeto | `CORE/PROJECT-MEMORY-TEMPLATE.md` | `CORE/PROJECT-MEMORY.md` |
| APIs | `SPECIALISTS/API-INTELLIGENCE.md` | `SPECIALISTS/API-ENGINEERING.md` |
| Qualidade | `SPECIALISTS/QUALITY-ASSURANCE.md` | `SPECIALISTS/QUALITY.md` |
| Segurança | `SPECIALISTS/SECURITY-AUDIT.md` | `SPECIALISTS/SECURITY.md` |
| Prompt de site | `PROMPTS/CINEMATIC-WEBSITE-PROMPT.md` | `PROMPTS/CINEMATIC-WEBSITE.md` |

Os caminhos da coluna de compatibilidade não foram removidos. Quando houver conteúdo complementar, ele pode continuar sendo consultado. Antes de consolidar conteúdo, comparar as diferenças e preservar os originais no arquivo histórico.
