04 / USAR COM O CLAUDE

ENVIE A SKILL.
PEÇA UMA TAREFA REAL.

  1. 01Baixe o ZIPSempre a versão mais recente da branch main.
  2. 02Envie ao ClaudeAnexe o ZIP ou o SKILL.md no projeto ou na conversa.
  3. 03Peça uma tarefaEle escolhe os módulos e pede autorização quando precisa.
  4. 04Confira a evidênciaResultado, hipótese e limites vêm separados.
PROMPT PARA COPIAR 
Leia SKILL.md e CORE/ROUTER.md. Analise minha tarefa, escolha apenas os módulos necessários, faça um plano curto, execute o que estiver dentro das ferramentas disponíveis e valide o resultado. Separe fatos verificados, hipóteses e pontos não verificados.
